# דוח הגשת פרויקט: מערכת ניהול בית-ספרית חכמה

## 1. מבוא ומטרת הפרויקט
מערכת ווב אינטראקטיבית ומתקדמת לניהול משתמשים ופעילויות במסגרת בית-ספרית. המערכת מיועדת לאפשר רישום נוח, ניהול גישה מבוסס תפקידים (תלמידים/מנהלים), וחיבור מאובטח בזמן אמת למסד נתונים בענן.

## 2. קישורים למערכת ולפרויקט
* **קישור למערכת החיה (Live Demo):** https://school-ai-site-production.up.railway.app
* **מאגר הקוד (GitHub Repository):** https://github.com/ainatomer-design/school-ai-site

## 3. ארכיטקטורה וסט טכנולוגיות (Tech Stack)
הפרויקט בנוי בארכיטקטורת Client-Server מודרנית:
* **צד שרת (Backend):** Python עם פריימוורק **Flask** לניהול ניתובים, בקשות HTTP ולוגיקת האפליקציה.
* **מסד נתונים (Database):** **Supabase** (PostgreSQL) בענן, הכולל ניהול טבלאות מותאמות אישית, אבטחת שורות (RLS) ומדיניות הרשאות מדויקת (`service_role`, `anon`, `authenticated`).
* **אחסון ופריסה (Deployment & Hosting):** **Railway** לפריסה אוטומטית שוטפת מתוך מאגר ה-GitHub (Continuous Deployment).

## 4. תהליך הפיתוח והתמודדות עם אתגרים הנדסיים
במהלך פיתוח המערכת התמודדנו עם מספר אתגרים טכנולוגיים ופתרנו אותם בהצלחה:
1. **התאמת סכמת מסד הנתונים (Schema Management):** התאמה מדויקת של עמודות טבלת המשתמשים (`users`) כך שיכילו את השדות הנדרשים בלבד (`id`, `name`, `role`, `class_code`, `created_at`), תוך ניקוי שדות מיותרים.
2. **ניהול אבטחה והרשאות (Permissions & Access Control):** פתרון שגיאות הרשאה מול PostgreSQL באמצעות הגדרת מדיניות גישה מפורטת ומפתחות מנהל (`SUPABASE_SERVICE_ROLE_KEY`) המאפשרים לשרת לבצע פעולות כתיבה וקריאה באופן מאובטח ותקין מול ה-Sequences והטבלאות.
3. **ניהול סביבות עבודה (Environment Variables):** הפרדה מלאה בין קוד המקור לבין נתונים רגישים וקישוריות לענן באמצעות משתני סביבה מאובטחים ב-Railway.

## 5. חדשנות וייחוד המערכת (מה שמבדל אותה מפתרונות קיימים בשוק)
1. **ארכיטקטורה מבוססת ענן מודרנית וגמישה (Serverless/BaaS Integration):** שילוב חסר פשרות בין שרת Flask קליל ומהיר לבין מסד נתונים מנוהל בענן (Supabase), המאפשר סנכרון נתונים בזמן אמת וניהול הרשאות ברמת האבטחה הגבוהה ביותר (`Row Level Security` ומפתחות `Service Role`).
2. **ממשק מותאם אישית לצרכים חינוכריים:** בניגוד למערכות ניהול גנריות ומורכבות מדי, המערכת תוכננה בקפידה כדי לתת מענה ייעודי ומהיר לאנשי חינוך – תוך דגש על פשטות תפעולית, ניהול שקוף של קוד הכיתה (`class_code`), ומניעת חיכוך טכנולוגי בזמן אמת.
3. **אוטומציה מלאה ב-Deployment:** שימוש בתהליכי CI/CD אוטומטיים דרך Railway ו-GitHub שמאפשרים עדכון קוד מהיר, שקט ורציף (Continuous Deployment) ללא השבתת שירות למשתמשים.

## 6. סיכום
הפרויקט הושלם בהצלחה, פועל בצורה יציבה בענן, ועונה על כל דרישות האפיון הפונקציונליות והאבזור הטכנולוגי.
